Squares are reference vertices. Component colours aid comparison; shapes, labels and arrowheads carry the same information. For valid structures, the number of selected arcs is n − k.

One arrow from every non-root

Follow the arrows. Where do you arrive?

In Wai-Kai Chen’s 1966 paper, a directed tree sends every non-reference vertex along a unique path toward the reference vertex. A directed k-tree allows k such components. Every vertex is retained, including isolated reference vertices.

Try following one path

Use the three diagrams above. Each step follows exactly one selected arc; reaching a square stops the walk, while revisiting a vertex exposes a cycle.

Terminology matters. Here k is the number of components. Chen’s object is a spanning forest oriented toward specified roots. It differs from the clique-based “k-tree” used in structural graph theory. Arrowheads indicate direction; squares mark roots; circles mark other vertices.

Original research group 1

1. Spanning forests directed toward roots

Original Research — Verbatim

From On Directed Trees and Directed k-Trees of a Digraph and Their Generation (1966), by Wai-Kai Chen

2. Definitions and preliminary considerations. A directed linear graph \(G(V,E)\) (or simply digraph G) consists of a set \(V\) of elements called nodes together with a set \(E\) of ordered pairs of the form \((i,j)\), \(i\) and \(j\in V\), called the directed edges (or simply edges) of the digraph; the node \(i\) is called the initial node and node \(j\) the terminal node. Together they are called the endpoints of the edge \((i,j)\).

For any \(i\in V\) the symbols \(\rho(i)\) and \(\rho^*(i)\) denote the cardinals of the sets of edges of \(G\) having \(i\) as initial and terminal nodes, respectively. They are called the outgoing and incoming degrees of \(G\) at \(i\). A digraph is regular of degree k if \(\rho(i)=\rho^*(i)=k\) for each \(i\in V\). A digraph is symmetric if it has the property that if \((i,j)\in E\), then \((j,i)\in E\).

A digraph \(S\) is a subgraph of \(G\) if the nodes and edges of \(S\) are nodes and edges respectively of \(G\) and if each edge of \(S\) has the same initial node and the same terminal node in \(S\) as in \(G\). If the node set and the edge set of \(S\) are both empty, then \(S\) is called the empty graph \(\varnothing\) of \(G\). A node not incident to any edge is called an isolated node. A digraph consisting only of isolated nodes is called the null graph. The empty graph is considered as a subgraph of every digraph. A directed circuit of \(G\) is a connected regular subgraph of degree 1. Two subgraphs are disjoint when they have no nodes in common. If \(S\) is a subgraph of \(G\) and each node of \(G\) is a node of \(S\), then \(S\) is a spanning subgraph of \(G\). A directed path \(P_{ij}\) is a sequence of the form \(P_{ij}=\) \((i,k_1)\) \((k_1,k_2)\) \((k_2,k_3)\cdots\) \((k_m,j)\in E\) where \(i,j,\) and \(k_t,\ t=1,\cdots,m,\) are nodes in \(V\). It is not required that all the nodes of \(P_{ij}\) shall be distinct. If they are, \(P_{ij}\) is said to be a directed simple path. Again node \(i\) is called the initial node of \(P_{ij}\) and node \(j\) the terminal node. Both nodes \(i\) and \(j\) are referred to as end nodes. A directed circuit (or a directed path) is of length m if the number of edges contained in the directed circuit (directed path) is \(m\).

If the order of two endpoints of an edge is immaterial, i.e., \((i,j)=(j,i)\), then the edge is called an undirected edge. An undirected graph is a graph in which every edge is undirected. To every directed graph \(G(V,E)\), there is also a corresponding undirected graph \(G_u(V_u,E_u)\) (or simply \(G_u\)) such that \(V_u=V\) and \((i,j)=(j,i)\in E_u\) if either \((i,j)\in E\) or \((j,i)\in E\) or both. Usually, a digraph \(G\) can be represented equivalently by a geometric diagram: The nodes are indicated by small circles, while any two of them, \(i\) and \(j\), are joined by an arrowheaded continuous curve, or even a straight line, from \(i\) to \(j\) if \((i,j)\in E\). Similarly, an undirected graph can also be represented equivalently by a geometric diagram such that there is a continuous curve from \(i\) to \(j\) if \((i,j)=(j,i)\in E_u\). More intuitively \(G_u\) of \(G\) can be obtained from \(G\) by omitting the arrowheads and combining the parallel curves. The geometric concept may be considered slightly general since each curve may be counted with a certain multiplicity. This will be excluded in this discussion. However, all the results obtained here can be extended easily, and the extension is almost trivial.

Sometimes, it is desirable to change an undirected graph \(G_u\) into a directed one \(G\) by the process of duplication: one replaces each undirected edge in \(G_u\) by two edges with the same endpoints; to the two edges in such a pair one assigns opposite orders (or directions). An undirected path \(P_{ij}\) of \(G_u\) is a sequence of undirected edges of \(G_u\) which has the same form as defined earlier for a directed path. \(G\) is said to be connected if, for any two nodes \(i\) and \(j\), there exists an undirected path in \(G_u\) with these two nodes as end nodes. A component of \(G\) is a maximal connected subgraph of \(G\). Let \(A\) be a subset of \(V\); then the sectional graph \(G[A]\) of \(G\) defined by \(A\) is the subgraph whose node set is \(A\) and whose edges are all those edges in \(G\) which connect two nodes in \(A\).

A tree t of \(G_u\) is a spanning subgraph which is connected and contains no undirected circuits. A spanning subgraph \(H\) of \(G_u\) is said to be a k-tree of \(G_u\) if \(H\) has \(k\) components and contains no undirected circuits. Some of the components may each consist of an isolated node. Very often, \(k\)-trees in which certain designated nodes are required to be in different components are used. For example, \(t_{ab,cde,f}\) is the symbol for a 3-tree in which the nodes \(a,b\) are in one component, the nodes \(c,d,e\) in one component, and the node \(f\) in one component. A subgraph, denoted by \(t^r\), of a digraph \(G(V,E)\) is said to be a directed tree if and only if (1) the corresponding undirected graph of \(t^r\) forms a tree in the corresponding undirected graph \(G_u\) of \(G\); and (2) \(\rho(i)=1\) for all \(i\in V-r\) where \(r\) is called the reference node of \(G\) and \(V-r\) is the node set with node \(r\) having been deleted from \(V\), and \(\rho(r)=0\). A subgraph, denoted by \(t^r_{r,i}\), of \(G\) is said to be a directed 2-tree if and only if (1) the corresponding undirected graph of \(t^r_{r,i}\) is a 2-tree in the corresponding undirected graph \(G_u\) of \(G\); (2) each of the two components of \(t^r_{r,i}\) is a directed tree for some sectional graph of \(G\); node \(r\) serves as a reference node for one of such directed trees; and node \(i\) for the other. The extension to directed k-tree is obvious. Again \(t^r_{ra,jbc,k}\) is the symbol for a directed 3-tree in which the nodes \(r,a\) are in one component; the nodes \(j,b,c\) in one component; and the node \(k\) in one component. Nodes \(r,j,k\) are the reference nodes of the components.

For a given set \(A\), \(\mu(A)\) is used to denote the number of elements in \(A\). For convenience, edges of a given digraph \(G(V,E)\) will also be represented by letters \(e_i\). Each subgraph \(Q\) of \(G\) may be expressed by the “product” or by juxtaposition of its elements provided that \(Q\) contains no isolated nodes; i.e., for example, a directed tree may be represented by \(e_{i_1}e_{i_2}\cdots\) \(e_{i_{\mu(V)-1}}\). Two set-theoretic binary operations, “union” and “intersection” represented by \(\cup\) and \(\cap\), respectively, will be used. \(g_1\cup g_2\) is a subgraph of \(G\) consisting of all elements which are either in \(g_1\) or in \(g_2\) or in both, where \(g_1\) and \(g_2\) are two subgraphs of \(G\). \(g_1\cap g_2\) is a subgraph consisting of all elements which are in both \(g_1\) and \(g_2\). Again if \(g_1\cup g_2\) contains no isolated nodes, then it may be represented by the product of its elements. Similarly for \(g_1\cap g_2\); i.e., for example, if \(g_1=e_1e_2e_3e_4\) and \(g_2=e_1e_4e_5e_6\), then \(g_1\cup g_2=e_1e_2e_3e_4e_5e_6\) and \(g_1\cap g_2=e_1e_4\).

Start with three vertices: what changes when a root is added?

A root is a stopping point, not an extra arrow. In the first graph, both non-roots must make an outgoing choice. In the second, making vertex 2 a root removes its outgoing choice. All three vertices are still present.

The same rule extends to any fixed root set R: every vertex outside R has outgoing degree one in the selected forest, every vertex in R has outgoing degree zero, and every vertex reaches a root.

Intuition → a precise membership test

Take all n vertices. At each vertex outside R choose exactly one outgoing edge; choose none at a root. Now follow each chosen arrow. If a walk enters a directed cycle, the selection fails. If every walk reaches a root, it is a directed k-tree with exactly one root per component.

\(d_F^+(v)=\) \(\begin{cases}0&v\in R\\1&v\notin R,\end{cases}\) \(|E(F)|=\) \(n-k.\)

Why this test is sufficient

  1. In a finite graph, repeated arrow-following either stops at a root or repeats a vertex, creating a cycle.
  2. If all walks stop, every vertex has a uniquely determined terminal root. The endpoints of any selected edge have the same terminal root.
  3. Every component therefore has exactly one root. A component on s vertices has s − 1 edges, and is connected, hence is an undirected tree.

A repeated example

Use vertices 1, 2, 3, 4, r. Select 1 → 2, 2 → 3, 3 → 4, 4 → r. There are four selected edges and one root, so k = 1.

Remove 3 → 4 and declare vertex 3 a second root. Now {1,2,3} and {4,r} are the two components. Merely removing the edge without changing the prescribed root set would fail the degree rule.

The invalid introduction instead selects 1 → 2 → 3 → 1 and 4 → r. Its four edges satisfy the degree rule but leave an unrooted cyclic component.

Boundary cases and an exact check

For k = n, every vertex is a root: the only spanning forest is the null graph on all n vertices. It has zero edges. For k = 1, all vertices must reach the single reference vertex. If a non-root has no available outgoing edge, no forest exists.

In the laboratory’s three-vertex complete symmetric graph, with root 3, there are four outgoing-choice assignments. One is the 1 ↔ 2 cycle; three are valid rooted trees. Browse all four under “Candidates” to check the definition directly.

Established: degree constraints plus root reachability characterize Chen’s forests. The edge count n − k follows from the definition; it is not by itself a sufficient test.

2. Ring-sum and edge-disjoint star products

Original Research — Verbatim

From On Directed Trees and Directed k-Trees of a Digraph and Their Generation (1966), by Wai-Kai Chen

3. Proposed algebra. Let \(D\) be the set of all subgraphs of a given digraph \(G(V,E)\). Consider the set \(H\) of all subsets of \(D\) for which an equivalence relation “\(=\)” is defined. Assume in \(H\) there are two binary operations. One of these binary operations is called the “ring-sum” and is denoted by the symbol \(\oplus\). The second of these operations is called “star” and is denoted by the symbol \(*\). These two operations are defined to satisfy the following rules: for \(h_1,h_2\in H\),

\(h_1\oplus\) \(h_2=\) \(\{x\mid\) \(x\) is in \(h_1,\) or in \(h_2,\) but not in both \(\},\)
\(h_1*\) \(h_2=\) \(\{x\cup\) \(y\mid\) \(x\in h_1,\) \(y\in h_2,\) and \(x\cap\) \(y=\) \(\varnothing\}.\)

It can easily be shown that the operations defined here are commutative and associative. Furthermore, the set \(H\) forms an abelian group with respect to the ring-sum operation, and a commutative semigroup with unity with respect to the star operation. The zero element in \(H\) is the empty set of \(H\) and is denoted by \(h_0=\{\ \}\), while the identity element is \(\{\varnothing\}\), where \(\varnothing\) is the empty graph of \(G\). For every \(h\in H\), \(h_0*h\) is defined to be \(h_0\); and the inverse of \(h\) relative to the ring-sum operation is itself, i.e., \(h\oplus h=h_0\).

Why does choosing an outgoing arc not finish the job?

Start with the symmetric triangle on vertices 1, 2, 3, with reference vertex 3. The choices are S₁ = {1 → 2, 1 → 3} and S₂ = {2 → 1, 2 → 3}. Their product has only four assignments. Inspect each before reading the general algebra.

Reciprocal arcs share one underlying edge identifier a₁₂. The other three assignments use two different identifiers and lead to root 3.

Two separate operations

Ring-sum cancels a term when it appears twice. Star rejects repeated underlying edge identifiers within a product. For the reciprocal pair u → v and v → u, both arcs use the same identifier {u,v}. Their product is rejected: that is Lemma 1’s elimination of a directed 2-cycle.

\(\{a\}\oplus\) \(\{a\}=\) \(h_0,\) \(\{a\}*\) \(\{a\}=\) \(h_0,\) \(\{\varnothing\}*\) \(\{a\}=\) \(\{a\}.\)
Implementation convention and a source ambiguity. The paper first defines intersection for subgraphs, including nodes, but its actual edge-letter expansion permits different edges to share endpoints. We therefore interpret disjointness in the generation algorithm as no repeated edge identifier, matching the paper’s edge-product expansion. Literal vertex-disjointness would reject ordinary trees. Also, a set-valued star product can erase multiplicities before ring-sum; our implementation retains expansion occurrences until parity is taken. This makes the paper’s operational cancellation precise without silently rewriting its verbatim algebra.

A transparent cancellation example

In a complete symmetric graph on vertices 1, 2, 3, r, choose the cycle 1 → 2 → 3 → 1 while leaving r isolated. Reverse that cycle. Both orientations produce the same undirected product \(a_{12}a_{23}a_{13}\). Their two occurrences cancel.

\(a_{12}a_{23}a_{13}\) \(\oplus\) \(a_{13}a_{23}a_{12}=\) \(0.\)
Orientation 1 of the same underlying triangle.

Why multiple cycles also cancel

This is an explanatory proof refinement. For a candidate with q ≥ 1 disjoint directed cycles of length at least three, each cycle has two orientations in a symmetric digraph. A fixed underlying edge selection therefore has \(2^q\) occurrences, an even number. Alternatively, choose the cycle containing the smallest-labelled cyclic vertex and reverse it; this gives a fixed-point-free involution. Rooted tree components have unique orientations toward their roots and contribute one occurrence.

The full PDF’s Lemma 2 proof says each element appears “exactly twice.” That describes the single-cycle case. The even-multiplicity argument above covers several disjoint cycles and supplies the needed general cancellation explanation.

Computational interpretation

Our parity implementation never asks whether a term is acyclic during expansion. It rejects repeated edge IDs and toggles a set entry for every occurrence. Direct enumeration separately follows paths in JavaScript and uses undirected union-find in Python. Equality of the resulting families, rather than just their sizes, is checked.

Established: repeated-edge rejection removes 2-cycles; even-multiplicity cancellation removes longer cycles in the symmetric completion. Keeping expansion multiplicities is essential.

4. Generation of directed trees.

(a) For symmetrical digraphs. Assume that the given digraph \(G(V,E)\) is symmetric, and all the nodes of \(V\) are labelled by one of the integers from 1 to \(\mu(V)\). Let \(C_1\) be the Cartesian product of the subsets \(S_k\), i.e.,

\(C_1=\) \(\prod_{\substack{k=1\\k\ne r}}^{\mu(V)}S_k,\)

where \(S_k=\) \(\{(k,t)\mid\) \((k,t)\in E\) and \(t=\) \(1,\) \(2,\) \(\cdots\) \(,\) \(k-1,\) \(k+1,\) \(\cdots\) \(,\) \(\mu(V)\}\) for \(k=1,2,\cdots,\mu(V)\), and \(k\ne r\), where \(r\) is an arbitrary node of \(V\). Thus \(C_1\) is the set of all subgraphs of \(G\) with outgoing degree 1 except at \(r\) where it is 0. It follows that the set of elements of \(C_1\) can in general be grouped into three disjoint subsets \(M_t,\ t=1,2,3,\) such that

\(M_1=\) \(\{c_i\mid\) \(c_i\in C_1,\) and \(c_i\) is a directed tree of \(G\},\)
\(M_2=\) \(\{c_i\mid\) \(c_i\in C_1,\) and there exists at least one directed circuit of length 2 in \(c_i\},\)
\(M_3=\) \(\{c_i\mid\) \(c_i\in C_1,\) and \(c_i\) is not a directed tree of \(G\) and contains no directed circuits of length 2 \(\}.\)

Since there exists a one-to-one correspondence between directed trees of a symmetrical digraph \(G\) and trees of the corresponding undirected graph \(G_u\) of \(G\), [7], it is simpler to consider \(G_u\) rather than \(G\), i.e., one considers \((i,j)=(j,i)\) for all \((i,j)\in E\). Consequently:

LEMMA 1. For each \(c\in M_2\), \(\{y_1\}*\cdots*\{y_{\mu(V)-1}\}=h_0\), where \(c=y_1y_2\cdots y_{\mu(V)-1}\).

LEMMA 2. \(\{c_1\}\oplus\) \(\{c_2\}\oplus\) \(\cdots\) \(\oplus\) \(\{c_{\mu(M_3)}\}=\) \(h_0\), where \(c_i\in M_3\) for \(i=1,2,\cdots,\mu(M_3)\).

THEOREM 1. In a given symmetric digraph \(G(V,E)\), let \(X_1=\) \(S_1*\) \(S_2*\) \(\cdots\) \(*\) \(S_{r-1}*\) \(S_{r+1}*\) \(\cdots\) \(*\) \(S_{\mu(V)}\), where \(S_k=\) \(\{(k,t)\mid\) \((k,t)\in E\) and \(t=\) \(1,\) \(2,\) \(\cdots\) \(,\) \(k-1,\) \(k+1,\) \(\cdots\) \(,\) \(\mu(V)\}\) for \(k=1,2,\cdots,r-1,r+1,\cdots,\mu(V)\), and \(r\in V\) is the reference node of \(G\). Also let \(T^r=\) \(\{x_1\}\oplus\) \(\{x_2\}\oplus\) \(\cdots\) \(\oplus\) \(\{x_{\mu(X_1)}\}\), where \(x_i\in X_1\) for \(i=1,2,\cdots,\mu(X_1)\). Then the set of all distinct directed trees \(t^r\) of \(G(V,E)\) is given by \(T^r\) provided \((i,j)\) and \((j,i)\) are considered identical in the operations.

Proof. By Lemma 1 it is apparent that \(X_1\) is the set union of \(M_1\) and \(M_3\). By Lemma 2 it follows that \(M_1=T^r\). This completes the proof of the theorem.

It should be noted that the expansion of \(S_1*S_2*S_3*S_4\) is very simple. It amounts to forming all combinations of edges without duplication of subscripts. From local choices to a global tree family

Each factor \(S_j\) contributes one outgoing edge from j. There is no factor for r. A Cartesian expansion enforces local degrees but allows cycles; the algebra removes precisely those cyclic candidates.

  1. \(C_1=\prod_{j\ne r}S_j\). Every assignment appears once before identifying opposite directions.
  2. Identify both orientations of each undirected edge. Reject every product that uses an edge identifier twice; this removes \(M_2\).
  3. Group the remaining terms by their unordered edge sets. Terms in \(M_3\) occur an even number of times and vanish under ring-sum.
  4. A spanning undirected tree has a unique orientation toward r. Its coefficient is one, so exactly the rooted trees remain.

Arbitrary digraphs: the missing bridge

Supplement from the full supplied PDF, §4(b), pp. 554–555; explanatory paraphrase. Add any missing reverse arcs to make G′ symmetric. Existing reverse arcs receive primes; artificially added arcs receive double primes. Perform generation after identifying the two orientations of each underlying edge. Orient the resulting trees toward r, then discard any tree using an artificial arc. A single prime does not mean an artificial edge.

5. Generation of directed k-trees.

(a) For symmetrical digraphs. Let \(C_2\) be the Cartesian product of the subsets \(S_j\), i.e.,

\(C_2=\) \(\prod_{\substack{j=1\\j\ne i_1,\cdots,i_{k-1},r}}^{\mu(V)}S_j,\)

where \(S_j=\) \(\{(j,t)\mid\) \((j,t)\in E,\) and \(t=\) \(1,\) \(2,\) \(\cdots\) \(,\) \(j-1,\) \(j+1,\) \(\cdots\) \(,\) \(\mu(V)\}\) for \(j=1,2,\cdots,\mu(V)\) but \(j\ne i_1,\) \(i_2,\) \(\cdots\) \(,\) \(i_{k-1},\) and \(r\). It follows that each element \(c\) of \(C_2\) is either a directed \(k\)-tree of the form \(t_{r,i_1,\cdots,i_{k-1}}\) or a subgraph which contains at least one directed circuit of length \(\geq2\). By eliminating the latter from \(C_2\) it can easily be shown that the remaining elements of \(C_2\) will give all possible directed \(k\)-trees of the form \(t_{r,i_1,\cdots,i_{k-1}}\) of \(G\). Thus, one may state:

THEOREM 2. In a given symmetric digraph \(G(V,E)\), let \(X_2\) represent the star operation of the sets \(S_j,\ j=1,2,\cdots,\mu(V)\) but \(j\ne i_1,\) \(i_2,\) \(\cdots\) \(,\) \(i_{k-1},\) and \(r\), where \(S_j=\) \(\{(j,t)\mid\) \((j,t)\in E,\) and \(t=\) \(1,\) \(2,\) \(\cdots\) \(,\) \(j-1,\) \(j+1,\) \(\cdots\) \(,\) \(\mu(V)\}\). Also let \(T_k^r=\) \(\{x_1\}\oplus\) \(\{x_2\}\oplus\) \(\cdots\) \(\oplus\) \(\{x_{\mu(X_2)}\}\), where \(x_i\in X_2\) for \(i=1,2,\cdots,\mu(X_2)\). Then the set of all distinct directed k-trees \(t_{r,i_1,\cdots,i_{k-1}}\), up to a null graph, is given by \(T_k^r\) provided \((i,j)\) and \((j,i)\) are considered identical in the operations.

(b) For arbitrary digraphs. Suppose \(G'(V',E')\) is obtained from \(G(V,E)\) by the process outlined in §4(b) and is labelled accordingly. The set \(T_k'{}^r\) of all directed \(k\)-trees of \(G'(V',E')\) is then obtained by Theorem 2 provided \(e_k\) and \(e_k'\), \(e_t\) and \(e_t''\) are considered, respectively, as identical elements in the operations. If those elements of \(T_k'{}^r\) which contain at least one double primed letter \(e_t''\) are eliminated, the remaining elements of \(T_k'{}^r\), up to a null graph, are the set of all directed \(k\)-trees of the form \(t_{r,i_1,\cdots,i_{k-1}}\) of \(G(V,E)\).

A tiny generalization: from one root to three

For the complete symmetric triangle, choose the roots before choosing any arcs. Each additional root omits one factor and creates one more component in every valid selection.

One omitted factor for each reference node

Replace the single root r by \(R=\{r,i_1,\ldots,i_{k-1}\}\). The only change to the outgoing-choice construction is to omit every factor indexed by a root. Rooted components can now terminate at any vertex in R.

\(C_R=\) \(\prod_{j\notin R}S_j,\) \(|E(F)|=\) \(n-|R|=\) \(n-k.\)

The same cycle-reversal argument applies: a component without a root contains a directed cycle and cancels; a tree component with its specified root has exactly one orientation. A component cannot contain two roots: in a connected component with s vertices and t roots, the degree sum gives s − t edges; a connected acyclic component requires s − 1, hence t = 1.

Why the principal minor counts these forests

This is an added derivation for unit-weight loopless digraphs. Write row i of the retained Laplacian as a sum over outgoing arcs: an arc i → j contributes \(\mathbf e_i^\mathsf T-\mathbf e_j^\mathsf T\) if j is a non-root, or just \(\mathbf e_i^\mathsf T\) if j is a root. Multilinearity of the determinant expands over one outgoing choice per non-root.

  1. A selected directed cycle makes the associated rows dependent: summing the rows around that cycle gives zero. Its determinant contribution is zero.
  2. For a valid rooted forest, order non-roots by distance from their terminal root. A simultaneous row-and-column permutation gives a triangular matrix with all diagonal entries one. Its determinant contribution is one.
  3. Summing these contributions gives exactly the number of forests rooted at the fixed set R.
\(\#\{F:\) roots exactly \(R\}=\) \(\det L_{V\setminus R,V\setminus R}.\)

For R = V the empty determinant is one, matching the unique null graph. This is not the number of all k-component forests with unspecified roots: each unrooted forest would otherwise be counted once for every choice of one root per component. Weighted network applications and general cofactors from the later paper are outside these experiments.

Established: the same local construction generates k components by omitting k factors. The source’s rooted 2-tree example gives six forests, and the principal-minor derivation explains the independent count.

How the pieces fit together

  1. Prescribe the roots. This fixes which outgoing factors are omitted and which rows and columns are deleted.
  2. Generate candidates. Select one arc at every non-root. Local degrees alone still allow cycles.
  3. Remove cyclic terms. Repeated-edge rejection and parity cancellation leave rooted forests in the symmetric completion; artificial-arc filtering restricts them to G.
  4. Count independently. Direct enumeration and the outgoing Laplacian principal minor give the same finite family size. The source examples give 12 for {r} and 6 for {3,r}.
