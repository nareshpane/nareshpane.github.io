# Original monograph illustrations

These 50 transparent SVGs are original drawings for the HealthDataNepal monograph. The supplied medical, pharmacy, server and analyst screenshots informed the subjects; no screenshot pixels or traced compositions are included. The compact assets use a 180 × 128 viewBox; the opening ecosystem uses 360 × 256, coordinated pastel fills, rounded shapes and consistent outlines.

- Patient journey: `physician`, `pharmacy`, `emergency`, `hospital`, `warehouse`, `analyst`.
- Foundations: `row`, `column`, `relation`, `schema`, `database`, `integrated-warehouse`.
- Keys: `primary-key`, `foreign-key`, `business-key`. Primary keys use rose, foreign keys green; labels supplement color in the page.
- Architecture: `secure-transmission`, `staging`, `integration`, `marts`.
- Selected technical topics: `aggregate`, `analytic-window`, `index`, `query`, `unique`.

Run `python validation/build_illustrations.py` from the asset directory to regenerate these drawings. Then run `python validation/build_diagrams.py` to embed the same geometry in the two self-contained overview figures. The page supplies contextual alternative text for each image; the SVGs also have their own accessible titles and descriptions.

The later teaching set is generated by `python validation/build_teaching_illustrations.py`:

- Dimensions: `dimension-date`, `dimension-geography`, `dimension-product`, `dimension-people`, `dimension-facility`, `dimension-diagnosis`.
- Query processing: `query-submit`, `query-parse`, `query-optimize`, `query-execute`, `query-fetch`.
- Transactions: `txn-dml`, `txn-undo-redo`, `txn-cache`, `txn-commit`, `txn-writer`.
- ETL: `etl-extract`, `etl-validate`, `etl-deduplicate`, `etl-transform`, `etl-load`, `etl-reconcile`.
- Instance overview: `instance-memory`, `instance-processes`, `database-files`.
- Opening chapter: `opening-ecosystem`.

The geography scene is an abstract hierarchy, not a claimed map of Nepal. The transaction scenes distinguish redo acknowledgment from independent data-file writes.
